# Credits

## Wallpaper

`backgrounds/jade-crane.png` is the Guofeng (国风) jade-mountain landscape that
inspired this theme: celadon mist, carved emerald peaks, gold-leaf ridges,
red-crowned cranes, and a distant pavilion.

It was provided by the theme author for redistribution with this theme under
the same MIT license as the palette and packaging files. If you fork the theme
and replace the wallpaper, update this file.

## Palette

Colors were sampled from the wallpaper (jade greens `#469e72`–`#2f7a56`, gold
`#b8954f` / bronze `#7a5f24`, crane vermilion `#c43a30`, parchment
`#f0efe6`) and tuned for Omarchy light-mode contrast on cream UI chrome.

## Icons

GTK icons: `Yaru-sage` (bundled with Omarchy / Yaru).
